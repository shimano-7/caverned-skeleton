# Stock Lens / caverned-skeleton

iPhoneのSafariで使える、日本株・米国株の日足CSV分析Webアプリです。外部ライブラリ・APIキー・ビルド作業は不要です。

## 使い方

1. 起動すると架空の日本株サンプル180本を表示します。「米国株」でドル表示の架空サンプルに切り替えられます。実在銘柄・実際の市場データではありません。
2. 「ひな形をダウンロード」で、サンプルデータ入りのCSVを保存できます。
3. 「CSVを取り込む」でiPhoneの「ファイル」からCSVを選びます。銘柄名は編集できます。市場ボタンで円・ドル表示を選択してください。為替換算はしません。
4. 90本・180本・全期間の表示切り替え、チャートのタップで日付・終値・移動平均・出来高を確認できます。
5. クロスの最新発生日と全履歴、買い・待ち・見送りの参考判定を表示します。

データはブラウザ内で処理され、サーバーに送信しません。保存機能はなく、再読み込みすると消えます。リアルタイム株価取得はありません。

## CSV形式

UTF-8（BOM可）、1ファイル1銘柄、日足、最大5MB・10,000行。

```csv
date,close,volume
2026-01-05,2850,1200000
2026-01-06,2875,1350000
```

- ヘッダーは `date,close,volume` または `日付,終値,出来高`。追加列や列順変更も可。
- 日付は `YYYY-MM-DD` または `YYYY/MM/DD`。昇順に並べ直します。重複日、不正日付、空欄、不正数値はエラーです。
- 終値は正数、出来高は0以上の整数。桁区切り付き数値は `"1,200"` と引用してください。
- 最低1本で表示、25本で25日線、75本で75日線、76本からクロス検出が可能です。
- 移動平均は取り込んだ日足の25本・75本の単純平均。表示期間を変更しても計算には全取り込みデータを使います。
- 休日・欠損日の補完はしません。連続した営業日データを用意してください。株式分割や配当を考慮する場合は調整済み終値を使用してください。

## 参考判定

- 買い：25日線が75日線より上、かつ終値が25日線より上。
- 見送り：25日線が75日線より下、かつ終値が25日線より下。
- 待ち：それ以外、または75本未満。
- ゴールデンクロス：前日の25日線が75日線以下、当日は上。
- デッドクロス：前日の25日線が75日線以上、当日は下。

出来高は表示用で、参考判定には含みません。履歴の最新クロスは最新日の売買指示ではありません。投資助言・利益保証ではなく、業績・ニュース等も含めた投資判断の参考情報です。

## ローカル起動・テスト

Node.js 24とPython 3を使用。依存パッケージのインストールは不要です。

```sh
cd /workspace/caverned-skeleton
npm test
npm start
```

開発PCではポート8000でHTTPサーバーが動きます。ES Modulesを使うため、HTMLをファイルとして直接開かずHTTP経由で利用してください。クラウド環境のループバックアドレスはiPhoneからアクセスできないため、以下の公開手順を利用してください。

`npm test` は移動平均・判定・両クロス・横ばい・CSV正常系/異常系・日米サンプルの7テストを実行します。

ブラウザ操作テストは `tests/browser.cjs`。Playwrightを別ディレクトリに入れ、サーバーを起動した状態で実行できます。

```sh
npm install --prefix /tmp/stock-lens-browser --no-package-lock playwright
NODE_PATH=/tmp/stock-lens-browser/node_modules node tests/browser.cjs
```

Chromiumは `/usr/bin/chromium` を使用。別パスなら `CHROMIUM_PATH` 環境変数で指定できます。390×844のモバイル相当画面と1280×900で検証します。これは実機Safariのテストではありません。

## iPhone Safariで開く公開方法（GitHub Pages）

公開用の `.github/workflows/pages.yml` を用意しています。公開の成否はGitHub Actionsの実行結果で確認してください。

1. この変更を `shimano-7/caverned-skeleton` の `main` ブランチにコミット・pushします。
2. GitHubのリポジトリで **Settings → Pages → Build and deployment → Source → GitHub Actions** を選択します。権限やプランによってPagesを使えない場合は、管理者の設定または対応プランが必要です。
3. **Actions → Deploy Stock Lens to GitHub Pages → Run workflow** を実行します。設定後のmainへのpushでも自動実行されます。
4. テストとデプロイが成功したら、Actionsの `github-pages` に表示される公開URLを確認します。標準URLは `https://shimano-7.github.io/caverned-skeleton/` です（公開前はアクセスできません）。
5. iPhoneのSafariでそのHTTPS URLを開きます。「サンプルを読み込む」、市場切り替え、グラフのタップを確認します。
6. 「ひな形をダウンロード」で「ファイル」にCSVを保存し、「CSVを取り込む」から選んで実機での読み込みを確認します。
7. 必要ならSafariの共有メニューから「ホーム画面に追加」できます。オフライン動作は提供していません。

公開されるファイルはHTML・CSS・JSだけです。ユーザーが選ぶCSVや認証情報はデプロイしません。

## 日本株の自動発掘（追加機能）

トップ画面は実データ専用です。既存の日米CSV分析と架空サンプルは「CSV分析・架空サンプルを開く」の中に残しています。架空データはランキングに使用しません。米国株・韓国株の自動発掘は未対応で、画面に準備中と表示します。

### 実データの接続設定

採用アダプターはJPXの **J-Quants API v2** です。`x-api-key` 認証で `/equities/master`、`/equities/bars/daily`、`/fins/summary` を使用します。API契約は直近株価と比較可能な2期分の通期財務が取得できる必要があります。遅延データしか利用できないプランでは鮮度基準によりランキング対象外になります。

**重要：本環境にはAPIキーがなく、公式仕様サイトも通信制限で参照できなかったため、現行v2 APIとの実接続・契約プランごとのフィールド互換性は未検証です。** 形式が違う場合は空ランキングと理由を出し、推定値を生成しません。APIキー設定後にまず更新結果を検証してください。

iPhoneでの設定：

1. GitHubのリポジトリ → **Settings → Secrets and variables → Actions → New repository secret**。
2. Nameは `JQUANTS_API_KEY`。SecretにJ-Quantsで取得したAPIキーを入力して保存。キーはチャットやソースに書かないでください。
3. **Settings → Pages → Source → GitHub Actions**。
4. **Actions → Deploy Stock Lens to GitHub Pages → Run workflow → main → Run workflow**。
5. 成功したら `https://shimano-7.github.io/caverned-skeleton/` をSafariで確認します。

APIキーを使うのはGitHub Actionsの更新処理のみで、静的サイトに出力しません。公開アーティファクトに含めるのは画面・計算モジュールと取得した市場データJSONです。**市場データそのものは公開されるため、公開再配信が許可された契約・利用条件を確認してください。個人向けAPIの契約が公開再配信を許可するとは限りません。** キーを隠すこととデータの再配信許可は別です。

### 取得対象・更新・制約

- 初期対象は東証プライムの銘柄コード昇順100銘柄。全日本株からのランキングではありません。画面に母集団・試行数・評価可能数を表示します。
- `.github/workflows/pages.yml` の `SCREEN_LIMIT` は5〜5000に変更可能。APIのレート・契約上限と更新時間を確認して拡大してください。1銘柄ずつ取得し、429時は待って再試行します。
- 平日19:30 JSTに更新予定（GitHub Actionsの遅延あり）、手動実行も可能。更新処理は最新レスポンスのみでJSONを再生成し、失敗時は過去のおすすめを引き継ぎません。
- 更新から36時間超、価格が7日超前、通期決算開示が460日超前、財務欠損、76本未満の価格は非表示または対象外です。休場が長いとランキングも非表示になります。
- APIキーなしでもデプロイは成功させ、画面では「取得できない」と表示します。**Actionsの緑チェックは市場データ取得の成功を意味しません。** ログの `Market data: ok` と画面の取得元・更新日時を確認してください。
- 株価・出来高は調整済み、PER・PBR・配当利回りの計算には未調整終値を使用。財務は直近通期実績（予想・TTMではない）。ROEは2期の平均自己資本を使用します。開示後の分割等によるEPS/BPSの変化は未調整なので注意が必要です。
- 最新クロスは取得期間内の最後の交差。RSIは14期間のWilder方式。出来高比は当日と直前20本平均の比較です。
- 12件のユニットテストで既存機能・財務・ランキング・欠損除外・RSIを検証しています。実データ接続と実機SafariはAPIキーと公開環境で別途検証が必要です。
